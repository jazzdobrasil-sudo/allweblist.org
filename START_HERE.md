## 🚀 Quick Start (5 Minutes)

### Step 1: Deploy to Vercel
```bash
# In your terminal:
git init
git add .
git commit -m "Initial commit"
git push to your repo
```

Then go to **[vercel.com](https://vercel.com)** → Import Repository → Deploy

### Step 2: Visit Your Site
- **Main Directory**: `your-site.vercel.app`
- **Submit Page**: `your-site.vercel.app/submit.html`
- **Admin Panel**: `your-site.vercel.app/admin.html`

### Step 3: Login to Admin
